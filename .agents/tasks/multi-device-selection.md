## Минимальный путь

1. Результат: API показывает доступные ADB-устройства и позволяет выбрать одно устройство на конкретную отправку.
2. Короткий canary: подключённый Android виден в `GET /v1/devices`; неизвестный serial отклоняется до попытки отправки.
3. YAGNI-срез: `device_serial` в запросах отправки, один заданный дефолт из `ANDROID_SERIAL`, только устройства со статусом `device`.
